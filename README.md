# 🎁 Home Love - Presentes Premium

Bem-vindo ao **Home Love**, uma plataforma de e-commerce especializada em presentes premium para o Dia dos Namorados e ocasiões especiais.

## 📋 Sobre o Projeto

Home Love é um site elegante e moderno desenvolvido com HTML, CSS e JavaScript, oferecendo uma experiência premium na compra de presentes personalizados.

### ✨ Características

- 🎨 Design minimalista e sofisticado
- 📱 Totalmente responsivo (mobile-first)
- 🛍️ Catálogo de produtos premium
- 💬 Depoimentos de clientes
- ❓ Seção de FAQ
- 🔒 Informações de segurança
- ⚡ Experiência de usuário otimizada

## 🚀 Início Rápido

1. Clone o repositório:
```bash
git clone https://github.com/bordalesbica/Home-love-.git
```

2. Abra o arquivo `html/index.html` no seu navegador

Ou se estiver usando um servidor local:
```bash
cd html
python -m http.server 8000
```
